# نزّلها — أداة تنزيل فيديوهات مناسبة للآيفون

واجهة عربية يمكن تثبيتها على الشاشة الرئيسية من Safari (PWA)، وخلفها سيرفر Python يستخدم `yt-dlp` لمعالجة الروابط العامة. المشروع لا يحتوي على مكتبة فيديوهات مستضافة.

## قبل الاستخدام

- استخدم الأداة فقط مع فيديوهاتك أو المحتوى الذي لديك تصريح بتنزيله.
- بعض المنصات، خصوصًا YouTube، تقيّد التنزيل خارج الخيارات الرسمية. راجع شروط المنصة وخيار التنزيل الرسمي قبل الاستخدام.
- لا تدعم الأداة تخطي DRM أو تنزيل الفيديوهات الخاصة أو تجاوز تسجيل الدخول.
- متغير `APP_PASSWORD` إلزامي لتفعيل واجهات المعلومات والتنزيل. لا تنشر الأداة بدون كلمة مرور قوية.
- الحد الافتراضي للملف 500 ميجابايت، والمدة 3 ساعات، وتُحذف ملفات التنزيل المؤقتة بعد 20 دقيقة.
- التنزيلات تُحفظ مؤقتًا على السيرفر أولًا ثم تُنزّل إلى الآيفون. استخدم HTTPS فقط، ولا تضع بيانات دخول المنصات في الأداة.

## تشغيل محلي باستخدام Docker

1. انسخ `.env.example` إلى ملف جديد اسمه `.env`.
2. غيّر `APP_PASSWORD` إلى كلمة مرور طويلة وفريدة.
3. من داخل مجلد المشروع شغّل:

```bash
docker compose up --build -d
```

4. افتح `http://localhost:8000`. صفحة صحة السيرفر: `http://localhost:8000/api/health`.

## النشر على Render

1. في Render اختر **New → Blueprint**، ثم اربط هذا المستودع ليقرأ `render.yaml`.
2. أدخل قيمة قوية وفريدة لـ `APP_PASSWORD` في إعدادات البيئة، ثم انشر الخدمة.
3. تحقق من مسار الصحة `/api/health`، ثم افتح عنوان HTTPS المنشور.
4. انتبه إلى موارد التخزين المؤقت؛ بعض الخطط لا تناسب تنزيل الملفات الكبيرة.

## التثبيت على iPhone

1. افتح رابط HTTPS المنشور في **Safari**.
2. اضغط زر المشاركة.
3. اختر **إضافة إلى الشاشة الرئيسية** ثم **إضافة**.
4. افتح الأيقونة وسجّل الدخول بكلمة مرور السيرفر.
5. الصق رابطًا عامًا، حلّله، اختر الجودة، ثم ابدأ التنزيل. قد يعرض iOS الملف داخل تطبيق «الملفات» أو معاينة قابلة للحفظ.

## إعدادات اختيارية

| المتغير | الافتراضي | وظيفته |
|---|---:|---|
| `MAX_FILE_MB` | `500` | أقصى حجم للملف بالميجابايت |
| `MAX_DURATION_HOURS` | `3` | أقصى مدة للفيديو بالساعات |
| `JOB_TTL_MINUTES` | `20` | مدة الاحتفاظ المؤقت بالملف |
| `MAX_ACTIVE_JOBS_PER_IP` | `2` | أقصى تنزيلات نشطة لكل عنوان IP |
| `MAX_ACTIVE_JOBS_GLOBAL` | `6` | أقصى عدد طلبات نشطة على السيرفر |

## تقنيات المشروع

FastAPI · yt-dlp · FFmpeg · PWA (HTML/CSS/JavaScript) · Docker.

**حالة التطوير:** تم رفع الهيكل الأولي للمشروع. لا تعتبر التنزيلات من المنصات الأربع مختبرة فعليًا حتى نجاح اختبارات الروابط العامة على السيرفر بعد النشر.
